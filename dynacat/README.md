# Home Assistant App: Dynacat

_A self-hosted dashboard focused on dynamic reloading and easy integration with
external applications, forked from Glance._

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

Runs the official [Dynacat](https://github.com/Panonim/dynacat) `3.0.0` image.
Configuration lives entirely in your own `dynacat.yml` — see [DOCS.md](./DOCS.md).
